# One Star for Monday

A one-star review of Monday as if it were a restaurant, for the [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61) bounty ($2).

> One star. Waited forty minutes for Monday, the coffee was cold, the waiter (me) looked exhausted, and they still charged a full week.

`main.ts` writes the line to `/output/entry.txt`. See [SPEC.md](SPEC.md) for the brief and why this one should win.
